# family-budget

Семейный бюджет: Android-приложение ловит уведомления и СМС банков, разбирает их в операции,
копит траты офлайн и отправляет в Google-таблицу через Apps Script. Таблица остаётся главным
местом учёта, приложение снимает ручной ввод.

Это публичная копия личного проекта без истории коммитов: маски карт, имена и ID таблиц
заменены на выдуманные.

## Устройство

```
packages/core   доменная логика и контракт API: разбор банковских текстов, дедупликация,
                холды, категории, сверка, расписание; без платформенных зависимостей
apps/mobile     Expo (Android): экраны, SQLite, Kotlin-модуль уведомлений и виджетов
gas             Apps Script таблицы (TypeScript, сборка в dist, деплой clasp)
design          макет экранов, генерируется из кода
```

Архитектура "ядро + адаптеры": вся логика в `packages/core` (чистые функции), мобилка и
Apps Script подключают её через порты. Контракт между ними один, в `packages/core/src/contract.ts`.
Деньги хранятся в копейках.

## Как сделан

Проект написан с Claude Code. Правила для агента лежат в [AGENTS.md](AGENTS.md): архитектурные
границы, где меняется контракт, как мигрировать таблицу, что прогнать перед коммитом.
Готовность подтверждается тестами (vitest, разбор реальных форматов уведомлений банков)
и CI на каждый push: typecheck, lint, test.

```bash
npm install
npm test
```
